# 공개 PR 60개: 라벨 전수 검수 및 B/C 비교

## 판단

**C 즉시 채택은 보류한다.** 동일한 `gpt-5.6-luna`의 입력 방식 비교이며, 서로 다른 모델 간 성능 비교가 아니다. C는 요구사항 보존을 개선했지만 비요구사항 오승격도 증가했다. 사전 기준인 “보존 개선 + 비요구/모호 승격 및 무효 응답 증가 없음”을 충족하지 못했다. 제품 코드·런타임 모델은 변경하지 않았다.

## 어디에서 개선되고 실패했나

- 개선: Starlette 버전 변경 본문, Ruff lexer 접근자 요구, Deno sourcemap 옵션 의미, Fiber의 sys/crypto 업데이트 본문 등이 C에서 보존됐다. 이는 선택된 본문을 해석하는 데 문맥이 도움을 줄 수 있다는 관찰이다.
- 퇴행: Express #7233의 basename 처리가 필요하다는 문장은 B의 요구사항에서 C의 모호함으로 내려갔다.
- 새 오승격: FastAPI의 향후 번역 PR 안내, Svelte의 이슈 종료 참조, Rust의 유사 rollup 생성 링크, Deno의 과거 동작 설명 등이 C에서 요구사항으로 올라갔다. 본문의 주변 문맥이 있다는 사실만으로 요청 권한이 생기지는 않는다.
- 남은 누락: C에서도 Django의 과거형 제목 4개를 구현 결과 주장으로 분류했다. 여러 의존성 업데이트 본문 역시 구현 주장으로 분류했다. 이것이 전부 동일 원인이라는 확정 진단은 아니지만, 다음에 검증할 구체적 경계다.
- 모델 앞단의 제한도 남는다. 요구사항 92개 중 89개만 전체 선택됐고, Django 별칭 해결 본문과 Ruff 의존성 표는 미선택, Svelte 취소 동작 목록은 부분 선택이었다. C는 추가 문맥을 제공할 뿐 새 후보를 추가하지 않는다.

## 라벨 및 측정 한계

- Astra/high가 원문 제목·본문 기준으로 60개 PR, 511개 라벨을 전수 검수했다. 9개 분류를 수정해 요구사항 92개, 비요구사항 385개, 모호함 34개로 고정했다. B/C 응답 생성 전에 검수 파일과 해시를 기록했다.
- **사람이 승인한 정답 데이터가 아니다.** 기계 제안 라벨을 감독 모델이 검수한 평가 주석이다. 과거형 제목의 명시적 목표를 의도로 인정하되, 완료된 구현 설명에서 요청 의도가 불명확하면 모호함으로 남기는 기준을 사용했다. 라벨의 규범적 해석에는 불확실성이 있다.
- 원문의 511개 구간, 텍스트, 순서, UTF-16 오프셋을 그대로 보존했다. 문단·목록·표 단위가 섞여 있고, 제목/본문에 중복 목표가 있어 92개가 서로 독립적인 92개 기능을 뜻하지 않는다. 부분 보존을 전체 성공으로 세지 않았다.
- 총 168개 라벨이 양쪽 모두 미선택됐다: 비요구사항 163개, 요구사항 2개, 모호함 3개. **미선택 비요구사항은 올바르게 제외했다고 판정한 성공 사례가 아니다.** 전체 385개 분모와 실제 선택된 222개 분모를 함께 제시한 이유다.
- C 문맥은 기존 15,000바이트 예산을 유지했다. 문맥 항목 37개가 예산 때문에 생략됐고, 인접 코드/HTML 참조 90개가 제외됐다. 전체 본문을 무제한 제공한 실험이 아니다.
- 10개 저장소별 6개라는 고정 층화 표본이다. 의존성 봇과 비슷한 템플릿 사례도 포함하며 모집단 대표성이나 통계적 유의성을 주장하지 않는다. 기존 8개 공개/6개 합성의 작은 실험과 전체 점수를 직접 비교하지 않는다.
- 이 결과는 Stage-A 출처 역할 분류다. 후속 요구사항 편입, 실제 코드의 요구사항 충족, 보안/테스트 성공을 검증한 결과가 아니다. 원문 속 테스트·보안 주장은 저자의 주장으로만 취급했다.

## 검증 및 산출물

- 구현솔(Sol/high)은 `prepare.mjs`, `summarize.mjs`, `self-check.mjs`만 구현했다. 라벨 판단·실제 API 실행·해석은 감독 Astra가 담당했다. 새 하위 에이전트나 작업은 만들지 않았다.
- 도구 자체 검사 통과: 정상 분할, 원본 해시/원문 구간, 미지 ID/중복/누락 리뷰 및 결과 거부, 예상 집계, 기존 출력 덮어쓰기 거부.
- 오프라인 4묶음 모두 통과, 호출 0회. 이후 기존 평가기를 15개씩 4묶음으로 실행해 각 30회, 총 120회, 재시도 0회. 네 실행 모두 정상 종료했으나 모델 응답 1개는 위와 같이 무효였다. 실행기 테스트 통과와 모델 응답 유효성을 구분한다.
- 모든 dry/live 사례의 입력·요청 해시, 선택, 설정 모델/프로필이 일치했다. 관측 응답 모델은 모두 `gpt-5.6-luna`였다. 원본 15개 아티팩트 해시와 485개 소스/설정 파일 동결 해시는 변경되지 않았다.
- 감독자가 기존 집계와 별도로 원문 문자 위치와 반환된 역할 구간을 열거해 **B/C 1,022개 평가 행**의 출처·오프셋·텍스트 해시·라벨·선택 범위·보존 결과를 재계산, 일치 확인했다.

- 실행 전 검수 파일 SHA-256: `3f28b6c097237effecd3ec731d333b31791caea12c881784f5d2c178b06043b1`.
